Six patterns every reviewer misses.

Each one is observable in any sufficiently large codebase. Each one is grep-able or rule-checkable.

Slop

AI code reads as AI code.

The same gradient on dark, the same three feature cards, the same "Empower your team" headline. Training-data reflexes.

Drift

Design systems drift faster than they are maintained.

One developer adds #f5f5f5. By month six there are dozens of near-identical grays. Theme switching breaks silently.

A11y

WCAG audits surface issues too late.

The consultant arrives two weeks before launch. Contrast violations across thirty components.

Noise

Security scanners drown signal.

Static analysis reports hundreds of theoretical issues. Real attack paths get buried.

Review

PR review catches typos, not architecture.

Reviewers approve the diff but never check whether the new component reimplements a shared primitive.

Copy

Em dashes mark prose as machine-generated.

The single most common signal of AI-written prose. So is delve, seamless, robust, elevate, pivotal.

Frequently asked.

Is it really free?

Yes. MIT licensed. No paid tier. No telemetry. Self-hosted entirely in your repo.

Does it require Claude Code?

The deterministic gate requires no AI tools at all. Only the full nine-phase verdict needs an LLM-capable runner.

What does it cost in CI minutes?

Under a second on a 10kloc repo for the script. With ripgrep install: about 30 seconds end to end.

What languages does it cover?

CSS, HTML, JSX, TSX, Vue templates, Svelte components, Markdown.

How do I add custom rules?

Edit quality-checks/scripts/check.sh and add a run_check call with your pattern.

Will it break my build immediately?

If your codebase has existing P0 or P1 findings, yes. Add a .qcignore file with glob patterns for grandfathered content.

Can I configure which homepage sections show?

Yes. Edit _data/homepage.json directly, or use the visual editor at /admin/.
